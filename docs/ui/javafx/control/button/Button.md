# JavaFX Control Button

## Structure

```
Button
|-- Text
```

## JUIM File

JComponentBuilder uses the Java UI Manager File, (.juim).

```
[Button:button0]
background.color=black;
background.radius=5;
hover.background.color=grey;
border.width=;
border.color=blue;
hover.border.color=green;
border.radius=;
text.align=center=;
text.color=white=;
```
