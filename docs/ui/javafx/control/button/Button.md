# JavaFX Control Button

## Structure

```
Button
|-- Text
```

## JUIM File

JComponentBuilder uses the Java UI Manager File, (.juim).

```
button0.background.color=black
button0.background.radius=5
button0.hover.background.color=grey
button0.border.width=
button0.border.color=blue
button0.hover.border.color=green
button0.border.radius=
button0.text.align=center
button0.text.color=white
```
